PBC proteomics

This repository contains the processed proteomics data and R scripts used for the analyses presented in the publication:
“Proteomic Profiling of Liver and Plasma Uncovers Biomarkers and Mechanisms in Patients with Primary Biliary Cholangitis”
Communications Medicine (2026).
DOI: 10.1038/s43856-026-01924-9

Repository contents
- data/ – Processed plasma and liver proteomics data used in the statistical analyses.
- scripts/ – R scripts used for statistical analyses and generation of figures.

Proteomics data
Raw mass spectrometry-based proteomics data are available through the ProteomeXchange Consortium via the PRIDE repository with the dataset identifier PXD083842.
